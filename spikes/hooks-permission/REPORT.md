## E1 print mode, PermissionRequest hook reply shape
`claude -p` DOES ask (Bash `touch`) and the hook fires (`hook_name":"PermissionRequest:Bash"`). Payload (runs/e1.jsonl): `session_id, transcript_path, cwd, prompt_id, permission_mode:"default", hook_event_name:"PermissionRequest", tool_name:"Bash", tool_input:{command,description}, permission_suggestions:[{type:"addDirectories",directories:[...],destination:"session"},{type:"setMode",mode:"acceptEdits",destination:"session"}]`. (No tool_use_id in the hook payload.) TUI payload adds `scratchpad_dir`.
| hook reply | observed (runs/e1_<mode>.out) |
|---|---|
| allow JSON | tool ran, file created |
| deny + message | tool NOT run; `permission_denied` event: `decision_reason_type:"hook"`, `message:"SPIKE-DENY-MSG-7431 not allowed by wrapper"`; the model's reply quotes `SPIKE-DENY-MSG-7431` -> deny message reaches the model |
| deny + `"interrupt":true` | accepted (no validation error); tool not run; run ended `subtype:"error_during_execution"`, `terminal_reason:"aborted_tools"`, process exit 1, no assistant text, message did not reach the model (it never got a turn) |
| `{}` / empty output (exit 0) | hook "success", falls through to normal prompt; in -p no one answers so denied: `permission_denied` "touch ... needs approval" |
| exit 1 (stderr "boom stderr") | `outcome:"error"`, `exit_code:1`, non-blocking, falls through to normal prompt (denied in -p) |
| invalid JSON `not json {` | `outcome:"success"`, ignored, falls through |
| `behavior:"ask"` | rejected: stderr in hook_response: `Hook JSON output validation failed — hookSpecificOutput.decision.behavior: expected one of "allow" | "deny"`, falls through. The full expected schema is printed there (allow: behavior, updatedInput?, updatedPermissions?; deny: behavior, message?, interrupt?). |
finding 1: PermissionRequest command hook allow/deny works in -p; deny message reaches the model; `interrupt:true` aborts the whole run (exit 1) -- runs/e1_denyint.out, e1_deny.out. Invalid/empty/exit-1/`ask` all silently fall through to the normal prompt (runs/e1_empty*.out, e1_ask.out). `--permission-prompts none` exists in --help ("anything that would prompt is denied") but was not run (NOT OBSERVED).
