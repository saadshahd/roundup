Name events and messages by grammatical mood. A command is a request that may be refused — name it imperative: an RPC method `noun.verb` (`todo.create`, `pad.setOwner`), or `VERB_NOUN` (`SUBMIT_ORDER`, `JOIN_ROOM`) for any other command tag. A fact already happened and cannot be refused — name it past participle: an event `noun.verbed` (`todo.created`, `pad.changed`) and its variant `NounVerbed` in PascalCase (`TodoCreated`, `RoomJoined`, `PaymentCaptured`). Never a tense-neutral noun.
_Avoid_: tense-neutral message nouns (`OrderSubmission`, `RoomJoin`) that hide whether the thing is a request or a result.
Detect: an RPC method that is not an imperative `noun.verb`, any other command tag that is not an imperative `VERB_NOUN`, or a fact's event name or variant that is not a past participle (`noun.verbed`, `NounVerbed`); a nominalized `-tion`/`-ing` form standing in for a command or a fact.
Not-when: the message is neither a refusable request nor a past event — a periodic tick, a telemetry record, or a protocol acknowledgement (`Heartbeat`, `PageView`, `Ack`) — where a tense-neutral noun is the accurate name and forcing it into either mood misdescribes it.
