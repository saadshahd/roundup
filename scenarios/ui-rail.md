A Pad has exactly one surface. What the user reads is where the user types. No Pad-level control switches the body between a reading, editing, preview or raw-source view. Visual blocks (Mermaid, drawings) render in place in that same surface. A focused block may expose its own text for in-place editing without changing the rest of the Pad. Whether the surface accepts typing is decided only by ownership (P2), never by a mode the user selects.
