Every Shelf row shows, at rest (no hover, no focus, Drawer closed), each fact the user decides on from that list: for a Todo, its status Glyph, `#<id>`, title, each open blocker and its Home. Every action that changes one of those facts (add, edit, block, unblock, complete, reorder, move) is reachable from the panel by a pointer-only path and by a keyboard-only path, in the row or in the item's Drawer, without typing an id from memory. Check: a harness test lists the facts in each row's DOM text with the pointer outside the list, and for each action drives both paths and reads the changed fact from the row.
