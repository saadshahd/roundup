**L91 affected CI.** One shared classifier, `loop/rules.sh lanes <base> <head>`, maps a PR's changed paths to the lanes `rust`, `web`, `rules` and `visual`. Changed paths include added, modified and deleted files and both sides of every rename. The file list must be complete: it comes from git between the merge base and the head, never a truncated API page. A path joins every lane that executes or reads it. `crates/`, `Cargo.*`, `rust-toolchain.toml`, `contracts/` and `spikes/` go to `rust`. `apps/`, `ext/`, `tools/`, `package.json`, `pnpm-*`, `tsconfig.json` and `.claude/skills/` go to `web`. `apps/desktop/src/` also goes to `visual`. `loop/`, `.agents/` and loop-only workflows go to `rules`. Documentation goes to a lane only when a test, lint or recipe of that lane reads it: `GLOSSARY.md` goes to `rules` (vocab), and scenario files go to every lane whose tests read them. All other docs go to no lane. A mixed change runs the union of its lanes. These shared inputs run every lane: the classifier and its tests, `.github/actions/`, `justfile`, `check.yml`, `loop.yml`, `visual.yml`, `merge-ready.yml`, and any path no mapping names. So do missing base history, an incomplete file list and a classifier error. A push to `main` runs every lane. Required status names `check`, `rules`, `merge-ready` and (for UI) percy are unchanged, and independent review and existing recipes are kept. A lane left out by the classifier's recorded decision counts as satisfied. A lane that is skipped, cancelled or missing without that decision fails its required gate. Each run's summary lists the lanes that ran and each lane left out, with the path set that left it out. Tests: `l91_*` in `loop/rules.test.sh`. Observer: classifier/gate tests, workflow lint, `just check`, independent review, and actual GitHub job selections recorded for a docs-only, a loop-only and a product PR.
