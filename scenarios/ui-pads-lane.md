Policy: U3787a (`scenarios/ui-mac-expectations.md`) replaces U486’s Pad-delete question/cancel clauses for reversible deletion with immediate deletion and undo. Owner permissions, dirty-draft protection, failure handling and refetch remain; irreversible actions still require native consent.

Owns `apps/desktop/src/pads/`, its own entries in `apps/desktop/src/copy.ts`, and only `.pad*` rules in `apps/desktop/src/styles.css`. No other lane, `ui/`, `keys/`, `tokens.css`, manifest, lockfile, contract or App seam change belongs here (policy). Reuse the existing shared wrappers and registry; an absent capability becomes a scoped native prerequisite, never a local replacement (policy). No new primitive or editor is specified.

**U486 Pad controls use shared accessible behaviour.** Given the Shelf's Pads list and an open Pad Drawer, when each icon-only control is revealed, hovered and keyboard-focused independently, then its accessible name is nonempty and its linked visible shared Tooltip shows that name (`u486_icon_controls_show_their_names`, planned under `apps/desktop/src/pads/`). Every icon-only control uses `ui/IconButton`; every tooltip uses `ui/Tooltip`, every menu `ui/Menu`, and every modal or confirmation `ui/Dialog` or `ui/AlertDialog` as appropriate (policy, inspect source and rendered controls). Text-labelled controls keep their button kind. Matching Ark components own any tabs, segmented choices or resize edges encountered in this ownership; no duplicate state machine is introduced (policy).

Given a truncated Pad name in the list or Drawer heading, when hovered and focused, then the full unchanged authored name is available in a shared Tooltip, without a native title (`u486_full_name_is_available`, planned in the same directory). This replaces only the Pad title-attribute requirements of U359 in `scenarios/ui-shelf-rows.md` and U431 in `scenarios/ui-drawer.md`; clipping and layout behaviour remain.

Given an editable Pad with the real Milkdown editor mounted, when each formatting control, including conditionally revealed controls, is hovered and focused, then it meets the icon-only/shared-tooltip rule above (`u486_editor_controls_show_their_names`, real-browser observer under `pads/`). Include the controls created by Milkdown's Vue renderer, not only JSX buttons. Record an exhaustive caller inventory and the interaction revealing each one in that test; source search alone cannot prove this clause (policy). Activating a formatting action preserves its effect on the selected text, active/disabled state, selection and subsequent editing focus (`u486_formatting_preserves_editing`, same real-browser observer). Native titles assigned through properties or DOM attributes are removed too (policy). Keep heading choices, readonly ownership and lazy editor cleanup passing through the existing U147 and U67 observers.

Given the open Pad's Delete action, when invoked, then a shared AlertDialog asks before any delete, includes the existing owner and dirty-draft warnings, and initially focuses Keep (`u486_delete_question`, planned under `pads/`). Keep, Escape and outside dismissal call no delete and return focus to the connected opener (`u486_delete_cancel`). Confirming sends exactly one `pad.delete` and preserves U150's close/refetch behaviour (`u486_delete_confirm`). A rejected delete keeps the Pad and Drawer, visibly shows the returned error and permits retry (`u486_delete_failure`). These clauses replace U150's Pad-only inline-question placement and Escape-closes-Drawer behaviour while the question is open; Todo acceptance is unchanged. Ark owns trapping, dismissal and focus return (policy). Preserve U346's real pointer hit-test and single-call regression with the new dialog placement.

**U487 Pad keys and copy preserve their meaning.** Given focus inside the Pads region or an owned open layer, when an existing Pad shortcut is pressed, then the registry selects only that scope's action; opening Help over it suppresses underlying actions, and disposal or Project switching leaves no stale callback (`u487_shortcuts_follow_focus`, planned under `pads/`, real wrappers and registry). Move owned shortcut subscriptions and component callbacks onto the registry; Ark owns menu/dialog navigation, and the editor library owns text editing. Delete the drawing block's native keydown subscription without losing dirty-change detection or source-byte preservation (`u487_drawing_changes_remain_dirty`, planned under `pads/`). Do not replace document-change tracking with an App shortcut or intercept native editor typing (policy).

Given the existing Pad creation/name field and any existing in-place rename reachable from Pads, when Enter commits, Escape cancels or focus leaves the field, then its prior request arguments, commit/cancel conditions, focus destination and visible failure behaviour remain unchanged (`u487_name_field_keeps_behaviour`, planned under `pads/`). This specifies no new rename method or feature and authorizes no Rail edits (policy).

All App-authored visible text, placeholders, errors and accessible names in this directory, including editor configuration and the deleted-Pad message, come from `copy.ts`; names, document text and returned error messages remain verbatim authored/returned content (`u487_copy_preserves_content`, planned under `pads/`, supplementing U471's catalogue observer). Add or edit only catalogue entries this directory uses (policy).
