# UI: attention, jumping and the Thread's input (U105 to U110)

Source: the user's $anchor rules on attention, navigation and ergonomics (2026-10-02/03). The Thread is the user's conversation with a Meta-agent (`CONTEXT.md`); "Main" in those rules is the Thread's Agent, and "main agent" is an _Avoid_ word. The Thread's input and feed have no scenario on main yet, so each clause below says "the Thread's input" and the Builder starts only when the Door scenarios land. Webview only: no App command and nothing under `contracts/`; U108 is a spike. Every clause is read on the injected emulator, the fake App and the U26 harness, with a fake clock.

**U105 typing dims the periphery.** Given an open Project, when the Thread's input takes focus and the user types a character, then within 120 ms (the crossfade row of `docs/motion.md`) the Rail, the status counters and every Live line and Terminal pane other than the Thread's input are at opacity 0.35; when the input is submitted (Enter) or loses focus, they return to 1.0 in the same time. Reduced motion changes both at once. The dim is a look only: no row, button or Card stops taking clicks, and a Decision (`needs-you`, Ink) still shows at opacity 1.0 so the one thing that blocks an Agent is never hidden. It narrows U4's 4.5:1 rule and U130–U137's contrast checks for the dimmed state only; they run again on the 1.0 state. Tests read the computed opacity of each region from the harness at both ends of the fake clock.

**U106 agent-to-agent Messages are one line.** Given `message.*` events for Messages between Agents (not to or from the user), then the Thread's feed shows each as one line, `<from> → <to> <kind> <first 60 characters>…`, and no body; `⌃O` expands every such line to its full body and `⌃O` again folds them. The toggle is the webview's, never reaches a Terminal (U45's rules), appears in U54's help and is not saved (U100's storage never holds it). Digest in `CONTEXT.md` means a child's state entry (B19), so this scenario says "folded line", not "digest". Tests: three Messages, the toggle both ways, a Message with a long body, a Message to the user (not folded), a fake emulator that receives no `⌃O`.

**U107 jump to an Agent.** Given an open Project and Agents in Rail order, when the user presses `⌥1` to `⌥9` (by key position, not by the character `⌥` produces), then the n-th Agent row of the Rail (Groups skipped, Terminals skipped, collapsed Groups counted) is selected, its Terminal takes keyboard focus and `takeover.begin {id}` is called (B6); `⌥0` calls `takeover.end {id}` and returns focus to the Thread's input; jumping to a second Agent ends the first Takeover before it begins the next. Typing `@` in the Thread's input opens U51's switcher over the Agents only, and choosing one does what `⌥n` does. A number with no Agent does nothing. After a Daemon restart the webview calls no `takeover.end` for a Takeover B8 says no longer exists. Tests use the fake App and record the order of calls.

**U108 (spike) the shell as a Drawer that becomes a Rail node.** Question: can `⌃\`` toggle a slide-out shell that, when minimised, stays alive as a Rail Terminal node (the Terminal is already a Rail node, `terminal.spawn`) without a fixed split pane? Exit: a prototype on the fake App showing toggle, minimise and reopen with its process alive and one `terminal.resize` per U13, plus a written answer on whether this needs a new App seam command. No Builder starts on this id; a Builder PR needs a scenario that replaces it.

**U109 an image pasted becomes an Attachment.** Given the Thread's input, when the user pastes or drops an image, then a compact Attachment token (its name and size) appears inline at the caret, and hovering it shows a floating preview of the image at its own size up to 480 px wide, which hides when the pointer leaves or `Esc` is pressed. The word is Attachment, not "chip" (Chip in `CONTEXT.md` is a Rail label) and not Token (a look value). What an Agent receives from an Attachment is a spike: the Adapter has no channel for image bytes, so the Attachment shows in the feed and nothing is typed into a Terminal. Tests: a stubbed clipboard and drop event, two Attachments, hover and `Esc`, a file that is not an image (refused with U80's one line).

**U110 select-to-quote.** Given text selected in the Thread's feed or in a Terminal's output, when the user then types a printable character in the Thread's input, then a Quote block is attached before the typed text: the selected text, up to 2000 characters (a longer selection is cut and marked `[cut]`), with its source (the Agent's name and the Message id or `terminal`). The character typed lands in the input after the block. A selection under 1 character or in the input itself adds nothing. Whether a quote is true to its transcript is the evaluator spike (B27). Tests use the injected emulator selection and the harness.

Tests are named `u105_` to `u110_` for the clauses with a Builder; U108 has an exit condition and no test.
