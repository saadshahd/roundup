# roundup

A lean, extensible, open-source Claude Code workbench: terminals, agents, todos and scratchpads. macOS only for now. No accounts, sync or telemetry.

Status: in development; the Daemon, `rup` and the macOS App run (`just app <project>`). See `docs/architecture.md`, `docs/wireframes.md` and `docs/extension-interface.md`. Terms are defined in `GLOSSARY.md`.

The CLI binary is `rup`; the daemon is `rupd`.
